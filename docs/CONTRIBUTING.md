# 3Dwork Klipper - Guía de Contribución

¡Gracias por tu interés en contribuir a 3Dwork Klipper! Esta guía explica cómo añadir nuevas impresoras, placas electrónicas y configuraciones.

---

## Estructura del Proyecto

```
3dwork-klipper/
├── boards/          # Definiciones de placas electrónicas
├── printers/        # Configuraciones de impresoras
├── macros/          # Macros globales de Klipper
├── klippy/          # Configuración de Klipper (mcu, extrusores, etc)
├── hotends/         # Configuraciones de hotends
├── extruders/       # Configuraciones de extrusores
├── sensors/         # Sensores de temperatura, etc.
├── steppers/        # Configuraciones de steppers
├── templates/       # Plantillas reutilizables
├── z-probe/         # Sondas Z (BLTouch, Probe, etc)
├── 4pin-fans/       # Ventiladores PWM 4 pines
├── chamber-*        # Filtros y iluminación de cámara
├── filament-sensors/# Sensores de filamento
├── toolboard/       # Configuraciones de toolboards
├── scripts/         # Scripts de utilidad
├── docs/            # Documentación
└── wizard/          # Herramienta de configuración
```

## Cómo Funciona el Sistema de Configuración

### Includes (Inclusión de Archivos)

Klipper permite incluir archivos de configuración usando la directiva `[include]`. **El orden es importante** - cada include añade configuración que puede ser sobrescrita por las siguientes.

```ini
# Ejemplo de printer.cfg
[include ../base.cfg]           # Primero: configuración base
[include ../boards/btt-manta-m8p/config.cfg]  # Placa electrónica
[include ../printers/voron-trident/voron-trident.cfg]  # Impresora
[include macros.cfg]            # Macros globales
```

### Alias de Pines (board_pins)

Las placas definen aliases de pines para facilitar la configuración:

```ini
[board_pins manta_m8p_tmc2209]
aliases:
  x_step_pin=PE2, x_dir_pin=PB4, x_enable_pin=PC11,
  fan_part_cooling_pin=PE6, heater_bed_heating_pin=PB7,
  # ... más pines
```

**Importante:** No sobrescribas los alias de la placa. Usa los pines directamente en tu configuración si necesitas cambiarlos.

### USER OVERRIDES

Para personalizar una configuración sin modificar los archivos originales, añade un sección `USER OVERRIDES` al final de tu `printer.cfg`:

```ini
############################
### USER OVERRIDES
### Anything custom goes here
############################

[bed_mesh]
probe_count: 11,11
speed: 50
```

## Añadir una Nueva Impresora

### 1. Crear directorio de impresora

```bash
mkdir printers/mi-impresora
```

### 2. Crear archivo de configuración principal

Crea `printers/mi-impresora/mi-impresora.cfg`:

```ini
# WARNING. DO NOT EDIT THIS FILE.
# To override settings, copy relevant sections to printer.cfg

[include ../base.cfg]

[heater_bed]
heater_pin: heater_bed_heating_pin
sensor_pin: heater_bed_sensor_pin
sensor_type: Generic 3950
min_temp: 0
max_temp: 140

[fan]
pin: fan_part_cooling_pin
shutdown_speed: 1.0

[printer]
kinematics: corexy
max_velocity: 300
max_accel: 1500
max_z_velocity: 15
max_z_accel: 20
```

### 3. Añadir variantes si es necesario

Algunas impresoras tienen variantes (diferentes tamaños, configuraciones):

```
printers/mi-impresora/
├── mi-impresora.cfg      # Tamaño base
├── 300.cfg               # Variant 300mm
├── 400.cfg               # Variant 400mm
├── input-shaper.cfg      # Config input shaper
├── speed-limits.cfg      # Límites de velocidad
└── macros.cfg            # Macros específicas
```

### 4. Incluir steppers y configuración

```ini
[include ../steppers/tmc2209.cfg]
[include ../klippy/extruders/bondtech.cfg]
```

## Añadir una Nueva Placa

### 1. Crear directorio de placa

```bash
mkdir boards/mi-placa
```

### 2. Definir pines con board_pins

Crea `boards/mi-placa/config.cfg`:

```ini
# WARNING. DO NOT EDIT THIS FILE.

[board_pins mi_placa_tmc2209]
aliases:
  # Steppers
  x_step_pin=PA0, x_dir_pin=PA1, x_enable_pin=PA2,
  y_step_pin=PA3, y_dir_pin=PA4, y_enable_pin=PA5,
  # ... más steppers
  
  # Heating
  e_heater_pin=PB0, e_sensor_pin=PB1,
  heater_bed_heating_pin=PB2, heater_bed_sensor_pin=PB3,
  
  # Fans
  fan_part_cooling_pin=PC0, fan_controller_board_pin=PC1,
  
  # Expansión
  EXP1_1=PD0, EXP1_2=PD1, EXP1_3=PD2, EXP1_4=PD3,

[mcu]
serial: /dev/mi-placa

[temperature_sensor Mi_Placa]
sensor_type: temperature_mcu
min_temp: 0
max_temp: 100
```

## Construir Firmware (Compilar)

### Requisitos

- Linux/WSL con Docker
- Klipper source
- Moonraker

### Método Manual

```bash
# 1. Clone Klipper
git clone https://github.com/Klipper3d/klipper.git

# 2. Configurar
cd klipper
make menuconfig

# 3. Compilar
make

# 4. Flashear
make flash SERIAL=/dev/ttyUSB0
```

### Con RatOS (referencia)

RatOS usa un sistema de build automatizado. Consulta su документация para más detalles.

## Añadir Configuraciones Especiales

### Input Shaper

```bash
# En el directorio de la impresora
cp ../templates/input-shaper.cfg .
```

### Filament Sensors

```bash
# Copiar configuración de sensor
cp ../filament-sensors/filament-switch-sensor.cfg .
```

### Toolboard (EBB)

```bash
# Configurar EBB36/EBB42
cp ../toolboard/ebb36.cfg .
```
